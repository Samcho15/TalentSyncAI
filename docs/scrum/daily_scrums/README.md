# Daily Scrum Records

This directory contains the Daily Scrum meeting records for the TalentSync AI Capstone I project.

## Purpose

The Daily Scrum meetings were conducted throughout each sprint to:

- Review progress made since the previous meeting.
- Discuss work planned before the next meeting.
- Identify blockers or challenges affecting progress.
- Maintain team communication and accountability.
- Ensure consistent progress toward Sprint Goals.

## Organization

The Daily Scrum records are organized by sprint:

```
daily_scrums/
├── sprint1/
├── sprint2/
├── sprint3/
├── sprint4/
└── sprint5/
```

Each sprint folder contains the Daily Scrum meeting minutes completed during that sprint.

## Scrum Questions

Each Daily Scrum documents responses to the following questions:

1. What was completed since the last Scrum meeting?
2. What is planned before the next Scrum meeting?
3. Are there any blockers or impediments?

## Project

**Project:** TalentSync AI – Secure AI-Assisted Recruitment Management Platform

TalentSync AI is a web-based recruitment platform that connects applicants and recruiters while leveraging AI-assisted resume analysis to improve the hiring process.

## Capstone I

These Daily Scrum records document the team's Agile/Scrum activities completed during Capstone I and demonstrate consistent project planning, communication, and sprint execution throughout the semester.
