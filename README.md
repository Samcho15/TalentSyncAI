# TalentSync AI

**TalentSync AI** is a secure AI-assisted recruitment management platform designed to streamline the hiring process through intelligent resume screening, candidate management, and recruiter workflow automation. This repository contains the planning, design, and documentation completed during **Capstone I**.

---

## Project Overview

TalentSync AI is designed to help recruiters efficiently manage job applicants by combining modern web technologies with artificial intelligence. The system is intended to provide:

- AI-assisted resume screening
- Candidate profile management
- Recruiter dashboard
- Role-based access control (RBAC)
- Secure authentication
- PostgreSQL database integration
- Cloud deployment planning
- RESTful API architecture

This repository primarily contains the project's planning and design documentation. Application implementation is planned for **Capstone II**.
